# flutter-robot-operator

**Simulation only. Not connected to a robot. Not a certified safety system.**

A Flutter operator app for one simulated diff-drive robot: waypoint missions with start, pause, resume and stop, a latched e-stop with bounded braking, a heartbeat deadman and a protective stop, all enforced on the robot side by a deterministic Dart simulation that runs both behind a WebSocket server and in the browser. See PLAN.md.
